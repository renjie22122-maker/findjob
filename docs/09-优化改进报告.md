# 09 优化改进报告

更新时间：2026-10-12。邮件时间、增量扫描、安全边界和配置以 [10 邮件自动化与安全边界](10-邮件自动化与安全边界.md) 为准。

## 本轮结果

- 修正 IMAP 嵌套 FETCH 导致的阻塞；只读邮箱，正确解码 MIME，收件时间使用 INTERNALDATE；兼容服务商报告大小与实际 MIME 不一致。
- 自动分析采用账号／文件夹／UIDVALIDITY 游标，只取新 UID；去重后不再下载已处理正文或重复调用模型。提供历史补扫和待处理重分析。
- 正文、PDF、DOCX、XLS/XLSX、TXT、CSV、ICS、HTML 文本纳入提取；附件 worker 有大小、时间与解析范围限制，不执行附件或访问外部资源。
- 投递、笔试／面试、Offer 使用各自的时间口径，展示证据及来源；缺时间、风险信息、附件失败进入待复核。
- 首封邮件就是笔试／面试时可以补建申请，实际投递日期未知。后补旧回执只补日期与历史事件，不回退当前状态。
- 模型输入中移除链接和常见验证码，身份验证主题本地跳过；不会自动打开一次性链接、验证身份、发信、提交考试或接受 Offer。
- 时间线及提醒幂等写入，准确匹配公司岗位，多岗位歧义拒绝自动关联。中间推断阶段记为说明笔记，不计入真实发生日期的趋势统计。
- 提供浅色／暗色／跟随系统及本地偏好记忆，适配图表、弹窗、消息、表单和移动端；邮件列表新增分页、来源、证据及复核提示。

## 合并保留的基础改进

本轮保留并验证工作区已有的查询参数校验、IP／SSRF 规则拆分、环境变量边界、服务优雅退出、统计聚合优化、请求超时／下载错误处理、React 错误边界、模型列表和类型检查入口。

## 验证

- 单元测试覆盖日期证据、无投递回执、历史回执补录、缺时间、同公司多岗位、重复应用、只读 IMAP、UID 增量与身份验证跳过，以及既有业务。
- 前后端 TypeScript 检查、生产构建及隔离数据库 API 集成测试通过。
- 合成 PDF、DOCX、XLSX 完整 MIME → worker → 文本提取通过；HTML／ICS 与禁用外部网络访问另有单元测试。
- Edge 无头浏览器验证暗色、浅色、跟随系统、刷新保留主题、确认弹窗、统计图表和 390px 移动端，无页面运行错误。
- 已使用现有配置真实测试：LLM 连通与时间提取成功；5 封真实邮件正文均成功解码；真实样本能识别无关邮件及投递确认。样本中无附件，未把合成附件验证描述为真实邮箱附件验证。

常用命令：`pnpm check`、`pnpm test:ui`。`pnpm test:email:live` 会访问实际邮箱和模型，并可能产生 API 费用，运行前会备份数据库。真实测试不修改申请和邮件追踪结果，仅审计及正常 OAuth 刷新可能写本地配置。

## 已知边界

- 服务运行期间才执行自动任务；单服务进程互斥，不支持多进程同时调度。
- 图片、扫描 PDF、加密附件、旧 DOC、压缩包和程序交给人工查看；本轮未加入 OCR。
- 复杂改期、多场考试、多轮面试以及公司／岗位别名仍需核对；原文证据存在不等于模型绝不会误解。
- 历史补扫有数量与资源上限；所有时间按本地时区解释，跨时区部署需保持时区一致。
- 已确认的旧版时间线不自动重写；待处理结果可重分析。模型输入脱敏是尽力过滤，不能保证覆盖所有秘密格式。
- 项目是无鉴权的单用户本地服务，默认监听 127.0.0.1，不作为公网多用户系统部署。
