# 秋招进度实时追踪（FindJob）

面向求职者的**秋招进度实时追踪工具**：记录投递的公司与岗位，追踪每一轮笔试/面试的进展，通过看板、时间线与统计图表实时掌握秋招全局。

## 功能特性

- 📊 **实时看板**：投递总数、各状态分布、Offer 转化漏斗、近 30 天趋势图（30s 自动刷新）
- 📋 **申请管理**：公司 + 岗位 + 完整投递状态机（待投递 → 已投递 → 笔试/面试 → Offer/已拒），非法流转被拒绝
- 🕐 **时间线**：每一次状态变更自动留痕，支持追加笔记事件，按时间线回看全程
- 🔔 **今日提醒**：笔试、面试、投递截止日期的站内提醒（过期高亮）
- 🕷️ **爬虫数据源**：一键抓取牛客网校招/实习职位（关键词搜索），预览勾选后导入追踪；注册表框架可扩展更多平台
- 📧 **邮件智能分析**：连接邮箱（IMAP），自动识别招聘相关邮件，按 UID 游标增量读取，解析正文及 PDF/Word/Excel/日历附件，调用已配置模型提取公司/事件/时间/岗位，自动或人工应用到时间线与提醒（无 Key 时规则降级）；支持 QQ/163/Gmail 授权码与 **Outlook OAuth2** 双模式
- 🌐 **官网投递追踪**：官网渠道 + JD 链接一键解析预填，进度统一走状态机
- 📥 **Excel 批量导入 / 导出**：按模板一键导入历史数据，支持任意筛选条件导出，无损往返
- 📄 **简历管理与 AI（v2）**：多版本简历，支持粘贴文本 AI 解析、GitHub 主页导入项目、学位证/毕业证图片识别（需视觉模型）；AI 生成简历并**按岗位微调**、简历审查、**岗位匹配打分**、定制求职信；HTML 导出/打印 PDF
- 🚀 **投递助手（v2）**：投递行动卡（材料清单 + 一键打开投递页 + 快捷标记已投递）+ **官网自动填表助手**（Playwright 实验性：按简历自动填充投递表单，人工核对后提交）；全自动投递因平台合规明确不做（半自动模式）
- 🎯 **抓取即匹配（v2.1）**：牛客网职位自动带出 JD 全文，抓取结果一键「AI 匹配排序」（匹配度分数条 + ≥70 分批量勾选导入）
- 🤖 **简历驱动岗位推荐（v2.4）**：从简历求职意向、技能和城市生成搜索画像，支持手动/每日/每周运行、匹配阈值、推荐收件箱、收藏/忽略与批量导入；内置 LinkedIn 合规辅助，可复制搜索词并粘贴岗位进行本地匹配
- 🌐 **公开视图（v2）**：导出静态 JSON/HTML 快照，一键 git 推送到 GitHub Pages 展示只读进度页
- 🔌 **数据接入层**：手动录入 / Excel 导入 / 爬虫三路统一入库，多源聚合抓取框架（`crawl/many`），适配器接口可扩展更多来源
- 🔍 **出站调用审计**：设置页可查每一次爬虫/邮件/AI/微软授权的出站调用（时间/目标/发送内容摘要/结果），凭据永不记录，数据流向有据可查

- 🌙 **浅色／暗色／跟随系统**：记住主题选择，图表、表格、弹窗与移动端同步适配。
- 🧭 **事件时间可追溯**：投递按收件时间，笔试／面试按正文或附件，Offer 优先录用日期；无投递回执时日期留空并关联后续招聘通知。

详细规则、增量游标、附件边界及配置见 [邮件自动化与安全边界](docs/10-邮件自动化与安全边界.md)。

同公司多个岗位按职位编号分别关联；未知岗位不再自动合并，可在确认弹窗选择已有申请或新建。线下考试时间与考位预约、打印准备事项分别记录，多考区需确认本人场次；首页显示未来 7 天待办提示。提醒在应用内查看，详情见上述文档。

📅 **招聘日程管理**：独立管理每场考试／面试，跨邮件和附件补充考点、地址、考场；改期、延期、取消、恢复更新本场提醒并保留来源历史。支持人工选场次，歧义不自动合并。见 [招聘日程管理](docs/11-招聘日程管理.md)。

## 技术栈

**短信与邮件统一跟踪**：支持粘贴短信和 Android Webhook 转发，自动筛选、脱敏与去重；多阶段预通知分别跟踪，时间冲突红色提示。配置见 [短信接入与多来源日程](docs/12-短信接入与多来源日程.md)。

**已有邮件核查**：邮件分析页 →「一键检查已有邮件」。增量分析及应用邮件后也自动核查，补齐有明确依据的提醒、清理重复自动待办；重复申请／日程及混入不同岗位的邮件先确认再处理。保留已完成状态、手工提醒和修复记录，核查仅使用本地数据，不重新读邮箱。详见 [核查规则与记录](docs/11-招聘日程管理.md#已有邮件核查)。

| 层 | 技术 |
| --- | --- |
| 前端 | React 18 + TypeScript + Vite + Ant Design 5 + TanStack Query + ECharts |
| 后端 | Node.js 20+ + TypeScript + Express 4 + better-sqlite3 + Zod + cheerio（JD 解析）+ imapflow（邮件接入） |
| AI 分析 | DeepSeek API（OpenAI 兼容接口，可配置其他模型），未配置时自动降级本地规则提取 |
| 数据库 | SQLite（本地单文件，零配置，`server/data/findjob.db`） |
| 工程 | pnpm workspaces + concurrently 一键启动 |

## 快速开始

环境要求：Node.js ≥ 20（推荐使用当前 LTS）、pnpm 11（项目已通过 `packageManager` 固定版本）。

```bash
# 1. 安装依赖（首次安装会自动下载 better-sqlite3 原生预编译产物）
pnpm install

# 2. 一键启动开发模式
pnpm dev
# 前端: http://localhost:5173 （API 自动代理到 3001）
# 后端: http://localhost:3001/api/health

# 生产模式（单端口，Express 托管前端构建产物）
pnpm build
pnpm start
# 访问 http://localhost:3001
```

## 使用指引

| 功能 | 操作路径 |
| --- | --- |
| 录入投递 | 投递管理 → 新建投递（可选「解析预填」从 JD 链接自动填标题/公司） |
| 推进状态 | 列表/详情页「推进状态」下拉（只展示合法流转项；终态可「重新打开」） |
| 创建提醒 | 投递详情 → 提醒卡片 → 新建提醒；今日待办页点击卡片标记完成 |
| 爬虫导入 | 数据源页 → 输入关键词/类型/页数 → 抓取 → 勾选 → 导入选中 |
| Excel 导入 | 设置页 → 下载模板 → 填写 → 导入 Excel |
| 邮件分析 | 设置页配置邮箱（QQ/163 用授权码、Gmail 用应用专用密码、**Outlook 走 OAuth2**）+ DeepSeek Key → 邮件分析页 → 增量分析／自动流程 → 核对时间来源（疑难结果保持待复核） |
| 自动导入 | 数据源页定时任务（每日/每周自动抓取牛客网并入库）或「抓取后自动导入」一键模式 |
| 简历找岗 | 智能推荐页 → 新建搜索画像 → 选择简历 → 保存并运行；结果可收藏、忽略或导入投递管理 |
| LinkedIn 辅助 | 智能推荐页 → LinkedIn 辅助 → 复制搜索文本到 LinkedIn；将本人查看到的岗位链接和 JD 粘贴回来做匹配 |
| 数据备份 | 复制 `server/data/findjob.db`；设置页支持导出全部数据 |

## 常用命令

```bash
pnpm dev            # 开发模式（前后端并行）
pnpm build          # 构建前后端
pnpm start          # 生产模式（单端口 3001）
pnpm test           # 后端单元测试（vitest）
pnpm typecheck      # 前后端 TypeScript 类型检查（tsc --noEmit）
pnpm test:integration # 隔离数据库的生产构建 + API 集成测试
pnpm check          # 单元测试 + 类型检查 + 生产构建 + API 集成测试
```

环境变量：`HOST`（监听地址，默认 `127.0.0.1`；仅在明确需要容器/局域网访问时设为 `0.0.0.0`）、`PORT`（后端端口，默认 3001）、`FINDJOB_DB_PATH`（数据库路径）、`CRAWL_RATE_LIMIT_MS` / `CRAWL_MAX_PAGES`（爬虫限速与页数上限）。

## 隐私与合规

- 单用户本地应用：邮箱授权码、OAuth2 Token 与 LLM API Key 仅存本地 SQLite，接口返回脱敏；
- 手动或定时分析会将脱敏正文及受支持附件文本发送给配置的 LLM 服务做相关性及事件提取；验证码主题本地跳过，URL 不访问，资源超限或身份验证提示转人工复核；
- 爬虫限速（≥1.5s/请求、默认最多 3 页），仅抓取公开职位信息用于个人追踪，不缓存分发；Boss直聘等强反爬平台列为实验性方案，需自行评估合规风险；
- 自动找岗只调用已注册的数据源适配器（当前内置牛客网）；LinkedIn 功能仅生成搜索文本和接收用户主动粘贴的岗位，不登录账号、不抓取页面、不模拟点击、不自动投递；
- **所有出站调用均有审计**：设置页「出站调用审计」面板记录时间、目标 URL、发送内容摘要、结果与耗时（凭据永不落日志）。

## Outlook OAuth2 配置（可选）

微软已停用 Outlook 密码登录，需 OAuth2 授权（设置页内置设备码流程）：

1. 打开 [Azure 门户](https://portal.azure.com) → Microsoft Entra ID → 应用注册 → 新注册；
2. 账户类型按需选择（个人账户选「仅个人 Microsoft 账户」）；
3. 重定向 URI：平台选「移动和桌面应用程序」，填 `https://login.microsoftonline.com/common/oauth2/nativeclient`；
4. 「身份验证」→ 高级设置 → **允许公共客户端流 = 是**；
5. 复制「应用程序(客户端) ID」→ 粘贴到 FindJob 设置页 → 点「连接 Outlook」→ 按弹窗提示登录授权即可。

> 若不方便注册 Azure 应用，QQ/163 授权码与 Gmail 应用专用密码无需任何额外配置，直接可用。
